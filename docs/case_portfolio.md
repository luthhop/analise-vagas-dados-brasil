# Case de portfolio: Analise de Vagas de Dados para Iniciantes no Brasil

## Contexto

Este projeto nasceu da necessidade de entender melhor o mercado de entrada em dados no Brasil. Em vez de escolher tecnologias para estudar apenas por intuicao, a proposta foi criar uma analise exploratoria sobre vagas de estagio, entrada e junior em dados.

A primeira versao usa uma base simulada para validar o pipeline completo. A proxima etapa planejada e substituir ou complementar essa base com vagas reais coletadas manualmente.

## Problema

Pessoas iniciantes em dados costumam encontrar muitas recomendacoes diferentes: SQL, Python, Excel, Power BI, estatistica, cloud, machine learning e outras ferramentas.

A pergunta central do projeto e:

**Quais habilidades aparecem com mais frequencia em vagas de dados para iniciantes no Brasil?**

## Solucao desenvolvida

Foi criado um fluxo completo de analise de dados:

1. Base inicial de vagas em CSV.
2. Tratamento dos dados com Python e Pandas.
3. Extracao de skills a partir das descricoes das vagas.
4. Criacao de tabelas processadas.
5. Carga dos dados em SQLite.
6. Consultas SQL para responder perguntas analiticas.
7. Geracao de relatorio executivo.
8. Dashboard interativo em Streamlit.
9. Documentacao para GitHub e portfolio.

## Principais perguntas analisadas

- Quais skills aparecem com maior frequencia?
- Quais modalidades de trabalho aparecem mais?
- Quais estados concentram mais vagas?
- Como a media salarial varia por nivel?
- Quais ferramentas uma pessoa iniciante deveria priorizar?

## Resultados iniciais

Na base simulada da versao inicial, SQL apareceu como a habilidade mais recorrente, seguida por Python, Power BI e Excel.

Esses resultados reforcam uma priorizacao realista para quem busca uma primeira oportunidade:

1. SQL
2. Excel ou Google Sheets
3. Power BI
4. Python com Pandas
5. Estatistica descritiva

A conducao humana ficou responsavel pela definicao do problema, validacao dos resultados, curadoria da narrativa e decisao dos proximos passos.

## O que este projeto demonstra

- Capacidade de transformar uma duvida de carreira em problema analitico.
- Organizacao de projeto de dados com estrutura clara.
- Uso de Python e Pandas para tratamento de dados.
- Uso de SQL para responder perguntas de negocio.
