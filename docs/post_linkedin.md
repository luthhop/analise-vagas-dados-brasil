# Rascunho de post para LinkedIn

Estou desenvolvendo um projeto de Data Analytics para entender melhor o mercado de entrada em dados no Brasil.

A ideia nasceu de uma pergunta simples, mas importante para quem esta buscando uma primeira oportunidade na area:

**Quais habilidades aparecem com mais frequencia em vagas de dados para iniciantes?**

Para responder isso, criei um projeto com:

- Python e Pandas para tratamento dos dados;
- SQLite e SQL para consultas analiticas;
- Streamlit para dashboard interativo;
- relatorio executivo com os principais insights;
- documentacao no GitHub;
- uso de IA como apoio no desenvolvimento.

Na primeira versao, usei uma base simulada para validar o fluxo completo do projeto. Os resultados iniciais apontaram SQL, Python, Power BI e Excel como habilidades centrais para quem busca vagas de estagio, entrada ou junior em dados.

O proximo passo sera complementar a base com vagas reais coletadas manualmente, mantendo rastreabilidade das fontes e evitando scraping automatico.

Esse projeto faz parte da minha construcao de portfolio enquanto estudo Ciencia da Computacao e direciono minha carreira para Data Analytics, com possibilidade de evoluir futuramente para Engenharia de Dados ou Ciencia de Dados.
